# rankwise site, v2 preview

A simpler version of `site/`: the SIMD lanes animation at the top, plain-language copy,
fewer demos. It uses `site/public` for its data. The Pages workflow builds it into
`site/dist/v2`, so it is served at `/v2/` next to the current site.

```bash
npm install
npm run dev     # http://localhost:5173
```
