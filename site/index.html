02Pruned networks

A median doesn't need
a full sort.

Each slice is sorted by a fixed sequence of compare-and-swap steps, called comparators. Ask for a few ranks, like the median, and rankwise skips every comparator that can't change them.

152comparators run
for the median (rank 15) · a full sort runs 186 · 18% skipped

Bright comparators run, faded ones are skipped. n is the number of values per slice. Tap an output on the right to add or remove a rank.

07Motivation

Why?

Order statistics operations using numerical libraries without GPU acceleration tend to be rather slow, but most CPUs today have excellent support for SIMD. rankwise puts these opcodes to use! If you're computing these types of operations without access to GPU hardware, this library should significantly speed up these maths, especially for batched data. rankwise uses a single Rust core to expose the same accelerated functionality to up to four languages, so you can drop it in place wherever you need.

On a GPU?

If you're running these types of algorithms on a GPU, you can probably do a lot better than rankwise, provided the RAM to VRAM transfer doesn't create a bottleneck.
